# Come importare le modifiche nel branch main

Questa cartella contiene soltanto i file modificati del portfolio.

## Procedura

1. Apri il repository `lucaluperto/portfolio` su GitHub.
2. Seleziona il branch `main`.
3. Carica nella cartella principale del repository tutti i file presenti qui, tranne `ISTRUZIONI.md`.
4. Quando GitHub segnala che alcuni file esistono già, conferma la sostituzione.
5. Crea un commit con un messaggio come: `Optimize portfolio positioning and recruiter journey`.
6. Controlla il sito pubblicato dopo l'aggiornamento di GitHub Pages.

## File da sostituire

- `README.md`
- `azzurro-ads.html`
- `build.py`
- `comedy-week.html`
- `index.html`
- `italy-food-prn.html`
- `kolms-creative.html`
- `style.css`
- `tip.js`

Nota: `build.py` è incluso per coerenza con il repository, ma non deve essere eseguito per pubblicare queste modifiche.
